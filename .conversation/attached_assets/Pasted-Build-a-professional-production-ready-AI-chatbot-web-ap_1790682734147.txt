Build a professional, production-ready AI chatbot web application called **Roblox Dev AI**.

The chatbot is specifically designed to help users with **Roblox game development, Roblox Studio, Luau/Lua scripting, game design, debugging, UI systems, gameplay mechanics, optimization, and game ideas**.

## 1. Main Goal

Create a modern AI assistant where users can ask questions such as:

* "How do I make a checkpoint system in Roblox?"
* "Give me a Luau script for a disappearing platform."
* "Why is my Roblox script not working?"
* "How do I make a sprint system?"
* "Give me ideas for a Roblox horror game."
* "How do I make a gamepass?"
* "How can I optimize my Roblox game?"
* "How do I make an obby?"
* "Explain this Roblox error."
* "Convert this script to a better/optimized version."

The AI should provide **professional, clear, accurate, beginner-friendly answers**.

The chatbot should feel like a professional Roblox development assistant rather than a generic AI chatbot.

---

# 2. AI API

Use the **Groq API** as the AI provider.

Do NOT expose the Groq API key in frontend code.

Store the API key in an environment variable:

GROQ_API_KEY

All AI requests must go through the backend/server.

Create a clean API abstraction so the AI provider can be changed later without rewriting the frontend.

Use a current Groq-supported model configured through an environment variable such as:

GROQ_MODEL

Do not hard-code the API key.

# 4. Professional Answer Format

The AI should structure answers depending on the question.

For coding questions, use:

### What we're building

Short explanation.

### Where to put it

Example:

ServerScriptService → Script

### Setup

Required objects and configuration.

### Code

Use a proper code block with the correct language.

### How it works

Short explanation.

### Test it

Steps to test inside Roblox Studio.

### Common problems

Potential errors and fixes.

Do NOT make every answer unnecessarily long.

For simple questions, give simple answers.

For advanced questions, provide deeper explanations.

If the user says:

and later says:

The AI should understand that "it" refers to the checkpoint system.

Send relevant conversation history to the Groq API.

Implement sensible message-history limits so very long conversations don't unnecessarily consume tokens.

# 14. Backend Architecture

Use a clean architecture.

Frontend:

* React
* TypeScript
* Modern CSS/UI framework if appropriate

Backend:

* Node.js
* TypeScript
* Express or another simple production-ready server framework

API endpoint example:

POST /api/chat

Request:

{
"messages": [...]
}

Response should support streaming if practical.

Prefer **streaming AI responses** so text appears progressively rather than waiting for the complete response.

Keep the architecture compatible with deployment on **Vercel**.

Avoid relying on long-running server processes.
